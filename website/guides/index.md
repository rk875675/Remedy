## Where to start

If you have never followed a back routine, start with [exercises for lower back pain](https://remedyrecoveries.com/guides/lower-back-pain-exercises), then read [how long to stick with it](https://remedyrecoveries.com/guides/how-long-to-stick-with-a-back-routine). Most routines fail on time, not on exercise choice. For individual moves, the [exercise guides](https://remedyrecoveries.com/exercises/) have step-by-step instructions.

If you want a plan instead of assembling one yourself, the [Remedy app](https://remedyrecoveries.com/back-pain-app) builds a multi-week program from a short onboarding. [Here is how it works](https://remedyrecoveries.com/how).
