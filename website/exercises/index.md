## How to use this library

Pick a few exercises from different groups rather than many from one. A useful routine covers mobility, core stability, and strength. [Exercises for lower back pain](https://remedyrecoveries.com/guides/lower-back-pain-exercises) has a ready-made starter routine, and [core exercises for back pain](https://remedyrecoveries.com/guides/core-exercises-for-back-pain) shows how the stability exercises progress.

If you would rather not assemble it yourself, Remedy picks from this library for you based on your answers, sets the reps, and moves you to harder versions as you go.
